# Блогикум

Финальный проект курса «Python-разработчик» (Яндекс Практикум, Django).
Социальная сеть для публикации постов: с пользователями, изображениями,
комментариями, отложенными публикациями и пагинацией.

## Стек

- Python 3.12+
- Django 5.1
- django-bootstrap5 (вёрстка готовых шаблонов)
- Pillow (изображения)
- pytest + pytest-django (тесты Практикума)

## Запуск

```bash
cd blogicum
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r ../requirements.txt
python manage.py migrate
python manage.py loaddata ../db.json   # необязательно: демо-данные
python manage.py createsuperuser
python manage.py runserver
```

Сайт доступен по адресу http://127.0.0.1:8000/, админка — `/admin/`.

## Тесты

```bash
# из директории django-sprint4/
pytest
```

## Что реализовано

**Ошибки.** Кастомные страницы 403 CSRF, 404 и 500 (`pages/views.py`,
`templates/pages/`). Обработчики подключены в `blogicum/urls.py`
через `handler404`/`handler500`, для CSRF задана настройка
`CSRF_FAILURE_VIEW`.

**Пользователи.** Подключены маршруты `django.contrib.auth.urls`
с переопределёнными шаблонами в `templates/registration/`.
Своя страница регистрации `/auth/registration/`, страница профиля
`/profile/<username>/` с информацией о пользователе и его публикациями,
редактирование профиля `/profile/edit/` и смена пароля `/auth/password_change/`
(ссылки видны только владельцу профиля).

**Пагинация.** По 10 публикаций на главной странице, странице пользователя
и странице категории.

**Изображения.** У публикации есть поле `image`; картинка выводится на главной,
на странице пользователя, на странице категории и на странице публикации.

**Публикации.** Создание — `/posts/create/` (только для авторизованных,
после сохранения — редирект на свой профиль). Редактирование —
`/posts/<post_id>/edit/` (только автор, тот же шаблон `blog/create.html`).
Отложенные посты (дата в будущем) и снятые с публикации видны автору
на его странице сразу, остальным — нет. Новые категории и местоположения
создаются только через админку.

**Комментарии.** Форма под текстом публикации, список комментариев
от старых к новым, количество комментариев в скобках в карточках публикаций.
Комментировать могут только авторизованные; автор может редактировать
и удалять свой комментарий.

**Удаление.** `/posts/<post_id>/delete/` и
`/posts/<post_id>/delete_comment/<comment_id>/` — с подтверждающей страницей
на существующих шаблонах (`blog/create.html`, `blog/comment.html`).

**Статичные страницы.** `pages/urls.py` переведён на CBV (`TemplateView`),
адреса `/pages/about/` и `/pages/rules/` не изменились.

**Почта.** Файловый бэкенд: письма складываются в `blogicum/sent_emails/`
(директория исключена в `.gitignore`).
